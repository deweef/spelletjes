# Bronnen: Kenney-pakketten (CC0, gratis)

Alle zips van Kenney staan in deze ene map, omdat sommige pakketten voor meer spellen bruikbaar zijn.
Claude Code pakt ze uit en kopieert alleen de modellen die een spel echt gebruikt naar de map van dat
spel (bijvoorbeeld `orkenstorm3d/assets/`). De zips zelf worden niet door de spellen geladen.

Uploaden: in GitHub **Add file → Upload files**, een paar zips per keer (max. 25 MB per bestand).

| Pakket | Voor | Waarvoor |
|---|---|---|
| retro-fantasy-kit | Orkenstorm 3D | kasteelmuren, torens, poorten, daken, hekken |
| mini-forest | Orkenstorm 3D | bomen, rotsen, tenten, boogschutter |
| mini-dungeon | Orkenstorm 3D | mannetjes (mens, ork), wapens, kisten |
| castle-kit | Orkenstorm 3D, Kasteelsprong 3D | kasteel, muren, torens, poort |
| animated-characters-protagonists | (reserve) | let op: alleen FBX en moderne skins (skater, cyborg); past niet goed in de middeleeuwen |
| mini-characters | Orkenstorm 3D | extra figuurtjes (werkers, ridders, genezer) |
| survival-kit | Orkenstorm 3D | orkenkamp: tenten, kampvuur, gereedschap |
| tower-defense-kit | Orkenstorm 3D | torens, orkentorens |
| graveyard-kit | Orkenstorm 3D (De Donkere Mijnen) | skeletten, graven, hekken |
| modular-cave-kit | Orkenstorm 3D (De Donkere Mijnen) | grotgangen voor de mijn |
| pirate-kit | Piratenbluf 3D | schip, kanonnen, schatkist, palmbomen |
| food-kit | Koekjesschuiver 3D | koekjes en ander lekkers |
| train-kit | later, bijvoorbeeld een treinspel | treinen, rails, stationnetjes |

Niet nodig: prototype-kit (grijze testblokken), blocky-characters (moderne poppetjes, passen niet),
hexagon-kit, modular-dungeon-kit (mini-dungeon en modular-cave-kit zijn genoeg).
