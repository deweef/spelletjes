# Bronnen voor Orkenstorm 3D

Zet hier de zip-bestanden van Kenney (gratis, CC0):

- Retro Fantasy Kit
- Mini Forest
- Mini Dungeon

Uploaden: klik in GitHub in deze map op **Add file → Upload files** en sleep de zips erin.

Claude Code pakt ze uit en kopieert alleen de modellen die het spel gebruikt naar `orkenstorm3d/assets/`.
De zips zelf worden niet door het spel geladen.
